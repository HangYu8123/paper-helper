# Portable writing style guide

Use this guide to draft a passage, revise existing prose, or word a review comment. Start with the core philosophy and quick reference in [writing-style-guide.md](writing-style-guide.md). For a thesis or long paper, see [field-conventions.md](field-conventions.md).

In Claude Code, this skill's folder is `${CLAUDE_SKILL_DIR}`. Resolve the links above from that folder.

When guidance conflicts, put the author's current instructions first, followed by the facts and definitions of the passage, the author's past choices, this guide, and field conventions.

## Companion skills

Read `writing-vocabulary` first when it is installed. Its `vocabulary.md` gives fixed meanings, familiar terms, and acronyms. Define terms where the audience needs them. Use `writing-style` for a disputed choice, a sentence that may have been reviewed before, or the evidence behind a preference.

Find a companion by skill name. Look next to this skill after standalone installation (`../<name>/`) or in the repository (`../../../<name>/skills/<name>/`), then use the skill path listed by the app. The portable guide works on its own.

To share the guide with another assistant, attach `writing-style-guide.md` and `field-conventions.md`. Attach `vocabulary.md` from `writing-vocabulary` if the task calls for technical word choice.
